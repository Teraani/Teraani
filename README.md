# 👋 Olá, eu sou Jayson Teraani

### Analista de Sistemas | Dados | Automação | PDV & ERP

Atuo desde 2012 com **sistemas de Ponto de Venda e ERP**, com experiência em ambientes de varejo envolvendo **Consinco, TOTVS e Emporium**.

Minha atuação combina **análise técnica, dados e visão de negócio** para investigar problemas, identificar causas-raiz e desenvolver soluções que gerem impacto real para a operação.

## 🔎 Minha atuação

* 🗄️ Análise e desenvolvimento de consultas em **SQL, Oracle e PL/SQL**
* 🔍 Investigação de anomalias e identificação de **causa-raiz**
* 🔄 Batimento e validação de dados entre diferentes sistemas
* 🛒 Análise de processos relacionados a **vendas, PDV e self-checkout**
* 🐍 Desenvolvimento de automações e ferramentas utilizando **Python**
* 📊 Criação de dashboards e ferramentas de análise com **Streamlit e Apache ECharts**
* 📈 Desenvolvimento de indicadores para acompanhamento operacional
* 🚨 Monitoramento de processos e identificação de inconsistências
* 🔧 Análise de logs e comportamento de aplicações
* ✅ Validação de correções e medição do impacto das soluções implementadas
* 🤝 Interface com áreas de negócio, desenvolvimento e equipes técnicas

# **App Name**: AmistososAI FC

## Core Features:

- Welcome View: Display a welcome screen with the app's logo, name, and a brief description.
- Dashboard Summary: Show the user's team name, partial score, total score, and valuation on the dashboard.
- Quick Actions: Provide quick access buttons on the dashboard for navigation to the lineup and market views.
- Interactive Lineup: Visually represent the user's team lineup on a stylized football pitch, including player positions.
- Player Market: Enable searching and filtering of available players in the market based on name, position, and team.
- Dynamic Player Stats: Display player statistics (points per round) in a bar chart.
- AI Player Suggestions: AI-powered tool for suggesting player replacements in the lineup based on real-time performance data, considering factors like player form, upcoming match difficulty, and team budget.

## Style Guidelines:

- Primary color: Saturated orange (#E67E22) to reflect energy and passion, balanced between approachability and boldness.
- Background color: Very light, desaturated orange (#F2D7BD) to provide a warm, neutral backdrop that does not distract from the content.
- Accent color: Yellow-orange (#D4AC0D) to highlight key interactive elements, creating contrast while complementing the overall warm palette.
- Body and headline font: 'Inter' sans-serif for a modern, objective, neutral look, suitable for both headlines and body text.
- Use clean, minimalist icons sourced from a consistent set to ensure visual uniformity. Icons will be orange when active and grey when inactive.
- Employ a tab-based navigation system at the bottom of the screen for easy access to the main sections (Dashboard, Lineup, Market).
